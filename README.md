# 🦁 Lion App — Organizador para Declaração de Imposto de Renda

## 📌 Sobre o projeto

O **Lion App** é uma ferramenta desenvolvida em Microsoft Excel com o objetivo de centralizar e organizar informações importantes para auxiliar na preparação da declaração de Imposto de Renda.

O projeto foi desenvolvido como parte de um desafio prático da **Digital Innovation One (DIO)**, aplicando conceitos de organização de dados, validação de informações, navegação entre abas e construção de uma interface funcional no Excel.

## 🎯 Objetivo

Criar uma ferramenta simples e organizada que permita ao usuário reunir informações financeiras e pessoais necessárias para facilitar o controle dos dados utilizados durante o processo de declaração.

## ⚙️ Funcionalidades

* Cadastro de informações do titular;
* Organização de informes de rendimentos;
* Registro de entradas financeiras;
* Validação de dados;
* Utilização de listas auxiliares;
* Organização das informações em diferentes abas;
* Navegação entre as áreas da ferramenta;
* Estrutura preparada para facilitar o preenchimento e consulta das informações.

## 📊 Estrutura da ferramenta

### 👤 TITULOS

Área destinada ao cadastro das informações do titular, como:

* Nome;
* CPF;
* Data de nascimento;
* Endereço;
* Telefone;
* Outras informações cadastrais.

### 🏦 INFORMES

Área destinada ao registro dos informes de rendimentos e informações relacionadas às instituições financeiras.

### 💰 NOTAS

Área destinada ao controle das entradas financeiras ao longo dos meses.

### 📋 TABELAS

Aba auxiliar utilizada para armazenar informações de apoio às validações e listas utilizadas na ferramenta.

## 🛠️ Tecnologias utilizadas

* Microsoft Excel
* Validação de Dados
* Fórmulas do Excel
* Listas auxiliares
* Organização e estruturação de dados
* GitHub para documentação e versionamento do projeto

## 📚 Aprendizados

Durante o desenvolvimento do projeto, foi possível praticar conceitos relacionados à organização de dados no Excel, criação de estruturas de preenchimento, validação das informações e documentação de um projeto técnico.

Além da construção da ferramenta, o projeto também proporcionou a experiência de utilizar o GitHub para publicar e documentar uma solução desenvolvida durante os estudos.

## 🚀 Como utilizar

1. Faça o download do arquivo `Lion App.xlsx`.
2. Abra o arquivo utilizando o Microsoft Excel.
3. Preencha as informações solicitadas nas respectivas áreas.
4. Utilize as listas e validações disponíveis para auxiliar no preenchimento.
5. Consulte as informações registradas sempre que necessário.

> **Observação:** esta ferramenta tem finalidade educacional e organizacional. Ela não substitui orientação de um contador ou profissional especializado em declaração de Imposto de Renda.
